Entry for the make.fun bounty "The Houseplant Out-of-Office": one out-of-office auto-reply, at most 120 characters, written as if a houseplant sent it.

The entry line:

> Out of office: I am a fern, ignored since March. I will reply when watered — probably never.

`main.ts` writes that line, byte for byte with no trailing newline, to `entry.txt` in the output directory. It guards the 1–120 character gate before writing.
